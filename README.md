# NetShield-AI
NetShield-AI is a Machine Learning-based Network Intrusion Detection System that identifies malicious network traffic using advanced data preprocessing, feature engineering, and classification models. The project analyzes network flow data and classifies traffic as normal or attack using supervised learning techniques.


A Machine Learning based Intrusion Detection System (IDS) for detecting malicious network traffic using CIC-IDS dataset. The system performs data cleaning, feature scaling, model training, and performance evaluation using classification algorithms.
